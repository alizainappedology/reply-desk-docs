API reference

Back to README

Base URL: http://127.0.0.1:8765. All API operations use POST with a JSON object. Production frontend and API share the same origin.

Request contract

Supply Content-Type: application/json and X-App-Token: <process-token>. The token is in the served HTML's meta[name="app-token"]. It changes on server restart. Only Host values 127.0.0.1:8765 and localhost:8765 are accepted. POST bodies must contain 1–128,000 bytes.

This token is local request protection, not a multi-user authentication system. Never send credentials to a public endpoint.

Routes

Route Request Successful response
/api/ai-status {} { "ready": true, "message": "..." }
/api/connect email, password, model { "ok": true }
/api/disconnect {} { "ok": true }
/api/inbox Optional filters below messages, total, offset, mailbox
/api/thread uid { "messages": [...] }
/api/draft uid, optional drafting fields { "draft": "..." }
/api/refine uid, body, refinement, optional drafting fields { "draft": "..." }
/api/summary uid, optional drafting fields { "draft": "summary text" }
/api/save uid, nonempty body { "recipient": "..." }
/api/send uid, nonempty body, recipient, confirmed, request_id { "recipient": "...", "sent": true }

AI status, connection, and disconnection do not require an already connected Gmail account. All other operations do.

Connect

{
  "email": "you@example.com",
  "password": "your-google-app-password",
  "model": "llama3.2:3b"
}

The model currently supports only llama3.2:3b for generation. Connection validates the Gmail login before replacing the stored credentials. The password is not returned.

Inbox filters

{
  "sender": "colleague@example.com",
  "subject": "project",
  "unread": true,
  "after": "2026-09-01",
  "before": "2026-10-01",
  "offset": 0
}

Dates are YYYY-MM-DD; after maps to inclusive SINCE and before to exclusive BEFORE. Offset is the number of results to skip. Results are newest UID first, with 20 items per page. UID order is mailbox arrival order, not a sort of the message Date header.

Messages contain uid, sender, reply_to, subject, date, and bounded plain-text body. The mailbox value namespaces local draft history and should be treated as opaque.

Drafting fields

{
  "uid": "123",
  "notes": "Thank them and ask for the deadline.",
  "tone": "Professional",
  "length": "Short",
  "intent": "Custom",
  "thread": true,
  "profile": {
    "name": "Your Name",
    "role": "Your Role",
    "signature": "Best regards,\nYour Name"
  }
}
  • Tone: Professional, Friendly, Firm, Casual.
  • Length: Short, Detailed.
  • Intent: Custom, Approve, Decline, Ask for details, Acknowledge.
  • thread defaults to true. Set false when All Mail is unavailable or context is unwanted.
  • Owner notes are bounded to 4,000 characters. Refinement drafts are bounded to 12,000 and refinement instructions to 2,000. Each profile field is bounded to 1,500.

Refinement adds body and refinement to these fields. Summary returns its output under draft for frontend compatibility; it does not send mail.

Confirmed send

{
  "uid": "123",
  "body": "The reviewed reply text.",
  "recipient": "sender@example.com",
  "confirmed": true,
  "request_id": "12345678-1234-1234-1234-123456789abc"
}

The server recomputes the reply address and rejects a mismatching recipient or absent confirmation. The UI creates a UUID request ID and reuses it for the same text if a request is retried. The server records attempted IDs per account before sending. Reusing an attempted ID is rejected, including after an uncertain outcome. This tracking lasts only for the current process; inspect Gmail Sent before retrying uncertain sends.

Errors

Errors generally return { "error": "human-readable message" }:

  • 400: malformed JSON, missing values, invalid UID/options, authentication or mailbox failure, rejected confirmation, repeated send ID, or an uncertain send outcome.
  • 403: invalid Host or absent/stale request token.
  • 404: unmatched operation.
  • 502: other local AI or connection failures.

Some locally caught AI errors are returned as 400 because they are represented as ValueError; clients should use the error message rather than infer all causes from the status code. Framework-level errors on unknown URLs may use FastAPI's detail format.

GET / serves React HTML, with 503 when the production build is missing. GET /assets/... serves only built frontend assets. Interactive /docs and /redoc are disabled. This guide is the supported route reference.
