Startup and ports

The app uses port 8765 and Ollama uses 11434. If 8765 is occupied, stop the other Reply Desk instance before starting another. Do not run multiple backend workers: process-local credentials and tokens would be inconsistent.

Use start.ps1 from the project root. It expects .venv\Scripts\python.exe and frontend\dist\index.html; run setup-app.ps1 if either is missing. On a fresh machine, run the local AI setup as well.

Closing the backend terminal clears app credentials but may leave the separately launched Ollama process running. To stop Ollama, identify the project's process before stopping it; do not indiscriminately terminate unrelated AI instances.

Diagnosing Gmail access

A custom company address is not automatically a Gmail mailbox. Confirm that the account is hosted on Google Workspace. An app password cannot override a company's disabled IMAP or SMTP policy. Use an administrator-approved account and client configuration.

Do not post passwords in issues or chat. Share only the visible error and the action that triggered it. The current UI intentionally uses a generic authentication error, so not all provider causes are distinguishable without a separate diagnostic.

Developer checks

.\.venv\Scripts\python.exe -m unittest discover -s tests -v
cd frontend
npm test
npm run build

The current pinned Starlette test client may emit a deprecation warning about httpx. A warning is separate from a test failure; check the final test result. Dependency upgrades should be validated with the same route tests before changing the test client.
