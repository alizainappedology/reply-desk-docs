User guide

Back to README

Connect your account

  1. Open http://127.0.0.1:8765/.
  2. Choose Account settings from the sidebar or top bar.
  3. Enter your Gmail address and a Google app password issued for that same account.
  4. Keep the local model set to llama3.2:3b and select Connect Gmail.

The password field clears after successful connection. Credentials remain in server memory. Disconnect explicitly to clear them. A server restart also clears them. Browser reload currently resets the visible connection state, so reconnect through settings when necessary.

Check local AI checks whether Ollama is running and the model is installed; it does not generate a reply.

Profile and signature

Expand Your profile and signature in account settings. Set your name, role, and preferred closing, then choose Save profile. Profile data is stored in your browser. Your saved signature is appended to generated replies; an explicitly requested exact-text response bypasses normal rewriting and signature insertion.

Find and read email

Expand Search & filters in the Inbox panel. Search by sender or subject, use unread-only filtering, or choose date bounds. From date is inclusive; Before date is exclusive. Choose Search / refresh to apply filters. Clear filters resets them.

Results contain up to 20 messages per page. Use Previous and Next for pagination. Select a message to view its body. Reading uses a read-only inbox and BODY.PEEK[], so it does not mark the message as read.

Draft a reply

Choose a tone, length, and reply intent in Reply studio, then add instructions. Useful examples:

  • Approve the adjustment and thank him for working late.
  • Politely decline and ask whether next week would work instead.
  • Ask for the budget and deadline. Do not promise a delivery date.

Choose Generate reply. The model uses the incoming message, selected options, your notes, and optional conversation context. Edit the result directly in Your reply.

For literal output, use Reply only with: Your exact text, Reply exactly with: Your exact text, or Say exactly: Your exact text. Otherwise, rough notes are converted to an email response.

AI behavior is probabilistic. Check whether the reply follows your decision and avoid sending invented facts, commitments, or deadlines.

Conversation and summaries

View conversation reads up to six recent messages belonging to the Gmail thread from All Mail. All Mail must be visible to IMAP. The selected message remains the target for saving or sending.

Leave Use conversation history when drafting enabled to include that context. If All Mail is unavailable, disable it to work from the selected email alone. Attachments are not read; HTML is reduced to plain text.

Summarize email produces Request, Deadlines, and Questions sections. It does not replace the editable reply. Verify the summary against the original email.

Refine and regenerate

Generate reply creates another version using your current instructions. The previous nonempty draft is recorded before regeneration.

Enter an editing instruction and choose Refine draft, or use Shorter or More polite. Refinement uses the current editable draft. Review the result for unintended changes to meaning.

Batch drafts

Check up to ten inbox messages, choose the shared tone, length, intent, and notes, then select Draft selected. Previously stored notes for another selected message may be reused for that message; otherwise it uses the current notes.

Processing is sequential. Stop after current finishes the active request before stopping the batch. Errors are reported per message. Open each email to inspect its prepared draft. Batch drafting does not save or send anything automatically.

Versions and local storage

Expand Draft versions for this email to restore a previous generated, refined, kept, saved, or sent version. Keep version records a manual edit. Restoring a version first keeps the current nonempty text.

The browser retains current drafts and up to 200 versions per mailbox, keyed by account and IMAP UIDVALIDITY. Clear this mailbox's local history removes the browser's current drafts and versions for that mailbox. It does not delete messages or drafts in Gmail.

Save or send

Save to Gmail Drafts creates a new Gmail draft with reply headers. It does not update a previously saved Gmail draft. Saving the same unchanged text again is disabled in the interface.

Send reply now shows a confirmation with the recipient, subject, and edited text. Cancel leaves the email unsent. Confirm sends through Gmail SMTP. The recipient is the original Reply-To address when present, otherwise From. This is a single-recipient reply, not reply-all.

Gmail draft saving and direct sending are separate actions. Sending does not remove any earlier Gmail draft.

If a save times out, inspect Gmail Drafts before retrying. If sending cannot be confirmed, inspect Gmail Sent before trying another send. History records confirmed sending, but is not proof that a recipient read the email.
